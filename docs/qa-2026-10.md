# Quality pass, October 2026

The A-to-Z pass before more sellers come in, run against master at `93fb110`.

What this file holds:

- the test matrix, used for the rest of the work: every feature, page, API endpoint, background job and cron, and how each is tested today;
- the findings: from the independent review (section 6) and from our own checks (section 7), with what was done about each.

Kinds of test:

- **unit**: a function tested on its own, no HTTP and no worker;
- **integration**: a backend test that calls the real FastAPI app (httpx `AsyncClient`) or runs a real job, with its own SQLite or scratch Postgres database and Etsy faked at the client or HTTP level;
- **e2e**: the Playwright layout test (`frontend/e2e/layout.spec.ts`) against a running production frontend, at 375 and 1366 px, signed in as the synthetic demo admin (1, 4 and 15 shops);
- **lib**: a frontend `node --test` test of a `frontend/lib/*.ts` module, or a structural check of a component's source;
- **none**: nothing tests it today.

Test counts at `93fb110`, before this pass: 165 backend test files (1662 tests), 60 frontend lib test files (311 tests), 18 e2e tests (each run in 2 viewports).
